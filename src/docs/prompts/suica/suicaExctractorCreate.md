# やりたいこと
Suicaの履歴データを抽出するためのモジュールを作成してほしい。

実際のデータの例は
@src\docs\examples\suica.md
に書いてあるので、それを見てほしい。

このデータなら、
```
08/29	ﾊﾞｽ等	ちばグリ	　		\23	-2,700

08/28	入	新宿　　	出	東京　　	\2,723	-208

08/28	ｶｰﾄﾞ	モバイル	　		\2,931	+2,910
```
の3つにチェックが入って、PDFをダウンロードしてくれるといいね
他にも
```
08/28	ｶｰﾄﾞ	モバイル	　		\241	+210

08/28	入	地八丁堀	出	地六本木	\31	-178

08/28	入	東金　　	出	八丁堀　	\209	-1,166

08/28	ｶｰﾄﾞ	モバイル	　		\1,375	+1,344
```
とかのやつもダウンロードできるといいね。
こういう感じで、
チャージされたもの、入出場したもの、バス等のものにチェックを入れてPDFをダウンロードできるようにしてほしい。
次のチャージ履歴が来るまでの間に入出場やバス等の履歴が複数あっても大丈夫。

# 制約条件
- TypeScriptで書くこと
- 勝手に構造を変更しないこと。
- PDFをダウンロードできるようにすること
- チャージ履歴
